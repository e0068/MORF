# MORF

**M**emory **o**f **O**bservations, **R**ules and **F**acts.

Порядок букв — это приоритет исходов, а не поток. Наблюдения делаются ради
правил: правило и есть основной выход, ради него очередь и существует.
Факты — исход побочный, для того, из чего действия не следует.

Сам поток обратный: наблюдения → факты → правила. Всё прослеживается до
сырого разговора и хранится обычными markdown-файлами:
подойдёт любой редактор, а Obsidian удобен схемой на холсте.

## Установка

Скачай `Install-MORF.command` из релиза и щёлкни дважды. Он спросит папку
хранилища и имя первого проекта, положит плагин в `~/.claude/skills/` и
разложит файлы в хранилище. Терминал не нужен, разрешений не спрашивает.

При первом запуске macOS предупредит о неподписанном файле: щёлкни правой
кнопкой → «Открыть» → «Открыть».

Через маркетплейс, если так привычнее:

```
/plugin marketplace add e0068/MORF
/plugin install morf@morf
```

## Что внутри

| Часть | Что делает |
|---|---|
| хук `SessionStart` | заводит строку в указателе, подметает оборванные сессии, сообщает неразобранный отрезок |
| хук `PreToolUse` | не пускает инструменты в архив разговоров |
| `/morf:handoff` | сверка в конце куска работы: копия транскрипта, счётчики, новые наблюдения |
| `/morf:why` | от строки к разговору, из которого она взялась |
| `/morf:audit` | ревизия порогов каждую десятую сессию проекта |
| навык `/morf` | порядок работы: что читать при старте, как сводить, куда что уходит |

Модель целиком — на холсте `Claude/Memory/модель-памяти.canvas`,
обоснование — в `Claude/Docs/`.
